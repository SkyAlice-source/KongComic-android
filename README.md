## Features

- **多源搜索** — 聚合多个漫画源，一键搜索
- **离线下载** — 支持 CBZ 打包，下载后随时阅读
- **本地收藏** — 多级文件夹管理，自定义封面
- **阅读器** — 多种翻页模式，自动滚动，图片缓存
- **备份恢复** — 收藏、设置、封面一键备份

## Build

```bash
flutter pub get
flutter build apk --release --split-per-abi
```
