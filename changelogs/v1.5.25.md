## English

### KongComic v1.5.25

- **Update download: cancellation and source switching.** Cancelling an update download now closes the HTTP connection immediately, from both the dialog and the notification, instead of waiting for the current chunk to finish. A new "Switch source" action continues the download on the next mirror while keeping the bytes already written; a route that stays below 48 KB/s after a 20-second grace period is switched automatically.
- **Page indicator.** The floating page indicator above the bottom bar is shorter, uses the same surface as the scroll-to-top button, hides while scrolling and no longer overlaps the navigation bar. The page-jump dialog no longer shows a decorative icon.
- **Cover loading.** The loading indicator is delayed by 320 ms so quick loads do not flicker, large cards display a download percentage, and failed covers retry once before offering a manual retry. Pull-to-refresh now also reloads covers that previously failed.
- **Crash fix.** Pulling to refresh in Favourites or Discover could fail with a type error, because two scroll views shared a single PageStorage slot. Each list now owns its slot, and a regression test covers it.
- **Other fixes.** Toast messages are no longer hidden behind the floating bottom bar; the download list has a proper empty state; failed downloads are shown in the error colour.

### KongComic v1.5.25

- **更新下载：取消与切换线路。** 取消更新下载现在会立即断开 HTTP 连接，对话框与通知栏均已生效，不再等待当前分块结束。新增「切换线路」，可保留已写入的字节改用下一条线路继续；线路在 20 秒宽限后速度仍低于 48 KB/s 时会自动切换。

- **崩溃修复。** 收藏页与发现页下拉刷新时，两个滚动视图共用同一 PageStorage 槽位导致类型错误；现每个列表使用独立槽位，并补充回归测试。
- **其他修复。** 提示条不再被悬浮底栏遮挡；下载列表补充空状态；下载失败的任务以错误色显示。

### KongComic v1.5.25

- **更新下載：取消與切換線路。** 取消更新下載現在會立即斷開 HTTP 連線，對話框與通知列均已生效，不再等待目前分塊結束。新增「切換線路」，可保留已寫入的位元組改用下一條線路繼續；線路在 20 秒寬限後速度仍低於 48 KB/s 時會自動切換。

- **當機修復。** 收藏頁與發現頁下拉重新整理時，兩個捲動視圖共用同一 PageStorage 槽位導致型別錯誤；現每個列表使用獨立槽位，並補充回歸測試。

### KongComic v1.5.25

- **アップデートのダウンロード：中止と配信元の切り替え。** アップデートのダウンロードを中止すると、ダイアログからも通知からも即座に HTTP 接続を切断するようになり、現在のチャンクの完了を待たなくなりました。新たに「配信元を切り替え」を追加し、書き込み済みのバイトを保持したまま次のミラーで続行できます。20 秒の猶予後も 48 KB/s を下回る回線は自動的に切り替わります。
- **ページインジケーター。** ボトムバー上のフローティングページインジケーターを短くし、トップへ戻るボタンと同じ素材に統一しました。スクロール中は非表示になり、ナビゲーションバーを覆いません。ページジャンプのダイアログからは装飾アイコンを削除しました。
- **表紙の読み込み。** 読み込み表示は 320ms 遅れて出現し、高速な読み込みでちらつきません。大きなカードはダウンロードのパーセントを表示し、失敗した表紙は一度自動で再試行したうえで手動の再試行を用意します。プル更新では、以前失敗した表紙も再読み込みされます。
- **クラッシュ修正。** お気に入りや発見でプル更新すると、2 つのスクロールビューが同じ PageStorage スロットを共有していたため型エラーが発生していました。各リストが個別のスロットを使用するようになり、回帰テストも追加しています。
- **その他の修正。** トーストがフローティングのボトムバーに隠れなくなりました。ダウンロード一覧に空状態を追加し、失敗したタスクはエラー色で表示します。
