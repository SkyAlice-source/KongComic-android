## English

### KongComic v1.5.13

- Reader loading animation replaced: the running cat is gone, replaced by a chibi crawling girl across every loading state. Her position along the track *is* the progress — she reaches the end exactly when the images finish.
- Indeterminate loads (no content length yet) keep her crawling in place, with a light band sweeping along the bar instead of a frozen empty track.
- Percent text removed: character position plus bar fill already encode progress twice, a third readout only added height and eye travel — especially in the small per-image cells.
- Loading dialogs now have a 120s watchdog so a forgotten `close()` can no longer leave a dialog stuck forever. Long tasks (import, export, folder scan) opt out explicitly.
- 403 / Forbidden / Access Denied no longer report "Login required". They now explain that the source is blocking the request (rate limit, region, Cloudflare) and suggest switching network or line.
- Fixed: the Impeller opt-out used a key that stopped working in Flutter 3.22+; switched to `flutter.impeller.enable` so Skia fallback actually applies.
- Cover save / cover view / update-page failures now show the real reason instead of a bare "Error" or "Network error".
- Local comic export no longer gets interrupted by the dialog timeout.
