## English

### KongComic v1.5.1

**Follow updates**

- Fixed the "Checking comic updates" notification staying in the tray forever once updates were found. Progress notifications now clean themselves up and are bound to their own check session.
- The check interval setting (daily / every 3 days / weekly) now actually takes effect — it was hard-coded to daily before.
- New: automatic background check once a day, running silently over any connected network.
- New: a Cancel button while checking. It now really stops the update engine instead of only hiding the UI.
- Fixed changing the followed folders wiping every "new update" badge in your library.
- Changing folders now only checks the newly added ones instead of re-scanning everything.
- New: "All Comics" entry to browse every favorited comic from the follow updates page.
- "Mark all as read" now commits in a single batch instead of refreshing once per comic.
- Fixed unchecking "All folders" leaving the whole list still selected.
- Fixed a blank screen on the follow updates page when there were comics with updates to show.
- A hint is now shown when notification permission is off, since check progress cannot be displayed without it.

**Reading & favorites**

- The update badge on the home page now refreshes immediately after you finish reading a comic.
- The extra leading colon in "Update Time" / "Upload Time" values is stripped (some comic sources include it in the value).
- The download chapters dialog no longer wastes a full status bar of space at the top.
- Fixed the favorites page showing two stacked toolbars; the Settings entry moved into the "More" menu.

**General**

- In-app update notes now follow the app's language (English / 简体中文 / 繁體中文) instead of dumping every language at once. Traditional Chinese now resolves to the correct section.

### KongComic v1.5.1

**追更**

- 修复：发现更新后，通知栏的「正在检查漫画更新」会永久常驻。现在进度通知会自行收尾，并与各自的检查会话绑定。
- 检查间隔设置（每天 / 每 3 天 / 每周）现在真正生效——此前被写死为每天。
- 新增：每天一次的后台自动检查，联网时静默执行。
- 新增：检查过程中的「取消」按钮，现在会真正停掉检查引擎，而不只是把界面藏起来。
- 修复：更改追更文件夹会把书库里所有的「有更新」标记清空。
- 更改文件夹时只检查新增的文件夹，不再全量重扫。
- 新增：「全部漫画」入口，可在追更页浏览全部收藏的漫画。
- 「全部标记已读」改为一次性批量提交，不再逐本刷新。
- 修复：取消勾选「全部文件夹」后，列表仍保持全选。
- 修复：追更页在有更新内容需要显示时整页白屏。
- 通知权限关闭时会给出提示——没有权限就看不到检查进度。

**阅读与收藏**

- 读完一本漫画后，主页的更新角标现在会立即刷新。
- 「更新时间」「上传时间」值前面多余的冒号会被去掉（部分漫画源把冒号一起抓进了值里）。
- 下载章节弹窗不再在顶部浪费一整个状态栏的高度。
- 修复收藏页顶部出现两条工具栏；「设置」入口移入「更多」菜单。

**通用**

- 应用内更新日志现在会根据 App 语言显示（英文 / 简体中文 / 繁體中文），不再把所有语言混在一起。繁体中文现在也会正确匹配对应段落。
