## What's Changed

- **Fixed: app updates always failed with "Download failed" in v1.3.7.** Every first-time download crashed internally before a single byte was written (an uninitialised field in the downloader). v1.3.7 could not download an update at all — reinstalling from the release page was the only way out. New downloads work again, and resuming an interrupted download still works as before.
- **Faster and more reliable app updates: download mirrors.** GitHub download links are frequently unreachable, so the app now works through several mirrors automatically. It tries the source that worked last time first, then GitHub directly, then each mirror in turn, and only switches when downloading or verifying actually fails. A watchdog moves on after 15 seconds without a single byte. **Settings → About** gained a *Download mirror* option — Auto (recommended), GitHub direct, any single mirror, or your own `{url}` template — plus **Test download sources**, which measures how quickly each source responds and flags the ones that are unavailable.
- **Fixed: sources kept showing an update badge after being updated.** The list backing the badge was a copy, so clearing it never took effect.
- **Fixed: a source could report success while still running the old version.** Repository indexes are cached per file at the CDN edge, so the index may advertise a version newer than the script it points to. Script downloads now bypass that cache, and when a repository really is out of sync, the app tells you which version was actually installed.
- **Fixed: updating a source could fail with "Multiple variants found".** Sources that share a key inside a catalogue were matched using the site address written in the script rather than the download address, so the match never succeeded. Matching now uses the download address, and a source that has disappeared from its own repository is looked up across all of your repositories.
- Chinese, Traditional Chinese and Japanese translations were updated for all the new text.

## 更新内容

- **修复：v1.3.7 里 App 更新必定「下载失败」。** 全新下载时会在写入第一个字节之前内部崩溃（下载器中一个未初始化的字段）。也就是说 v1.3.7 完全无法通过自更新升级，只能去 Release 页面手动重装。现在全新下载恢复正常，断点续传依然照常可用。

- **修复：漫画源更新后仍显示「更新」红点。** 角标背后的列表是副本，清除操作从来没有生效过。
- **修复：源提示更新成功，实际却还是旧版本。** 仓库索引在 CDN 上按文件分别缓存，索引里写的版本号可能比它指向的脚本更新。现在下载脚本会绕过缓存；如果确实是仓库本身不同步，会明确告诉你实际安装的是哪个版本。

- 同步更新了全部新增文案的简体中文、繁体中文与日文翻译。

## 更新内容

- **修正：v1.3.7 ではアプリの更新が必ず「ダウンロードに失敗」する問題。** 初回ダウンロード時に、1 バイトも書き込む前に内部でクラッシュしていました（ダウンローダーの未初期化フィールド）。v1.3.7 ではアプリを更新する手段がなく、リリースページから手動で入れ直すしかありませんでした。新規ダウンロードが再び動作し、中断したダウンロードの再開も従来どおり機能します。
- **アプリ更新をミラーで高速化・安定化。** GitHub のダウンロードリンクは到達できないことが多いため、複数のミラーを自動で試すようになりました。前回成功したソース → GitHub 直接 → 各ミラーの順に試し、ダウンロードまたは検証に失敗した場合のみ切り替えます。15 秒間データが流れないソースは自動的にスキップします。**設定 → アプリについて** に「ダウンロードミラー」（自動（推奨）／GitHub 直接／各ミラー／`{url}` テンプレートのカスタム）と、各ソースの応答速度を計測して利用可否を表示する「ダウンロード元をテスト」を追加しました。
- **修正：更新後も「更新」バッジが残る問題。** バッジの元になるリストがコピーだったため、削除しても反映されませんでした。
- **修正：更新したのに古いバージョンのままになる問題。** リポジトリのインデックスは CDN でファイル単位にキャッシュされるため、インデックスが指すスクリプトより新しいバージョンを告知することがありました。スクリプトのダウンロードでキャッシュを回避し、リポジトリ側が実際にずれている場合は、インストールされたバージョンを明示します。
- **修正：「Multiple variants found」でソースを更新できない問題。** カタログ内でキーが重複しているソースを、スクリプト内のサイトアドレスで照合していたため一致しませんでした。ダウンロードアドレスで照合するようにし、所属リポジトリから消えたソースは手持ちの全リポジトリを横断して探します。
- 新しいテキストの簡体字中国語・繁体字中国語・日本語の翻訳を更新しました。
