## English

### KongComic v1.5.5

**Favorites**

- New overview layout. Opening Favorites now shows one shelf per folder — scroll sideways through it, see how many comics it holds, tap "All" to open it — instead of dropping you straight into a single folder's grid. Pressing back inside a folder returns to the overview first.
- Added a "Recommended" shelf at the bottom: picks similar to whichever tag you favourite most, with anything you already have filtered out. If nothing can be loaded, the shelf quietly disappears instead of leaving an empty box behind.
- Folder counts in the sidebar now stay in sync right after you favourite or unfavourite something.

**Comic details**

- Chapter ordering is now a two-state control that shows which order is active, instead of one icon that looked the same either way. Switching order keeps you where you are in the chapter list.

**Lists**

- The page selector is now a single compact bar pinned to the bottom of the screen, instead of a full-width row at the top. It stays within thumb reach, and you no longer have to scroll to the very end of a page to reach "next".
- Fixed skipping sideways through tabbed lists triggering Android's system back gesture on the Categories and Explore pages. The tab strip is excluded from the system back area, and those pages no longer drag sideways on their own.

**Storage & permissions**

- Automatic backups no longer assume a hard-coded Download path. They try the public KongComic folder, app storage, then internal storage, and treat "I can actually write the file" as the real test — previously a folder that existed but could not be written made every backup fail with nothing more than a generic error.
- Fixed the "folder unavailable" warning vanishing too early. Switching to a different folder clears your warning even though your old files stayed behind; it now stays visible until you genuinely return to the original folder (or dismiss it yourself).
- Settings gained a Notifications row: it shows whether notifications are allowed and opens the system notification page, so you can turn them back on after denying the prompt once — Android 13+ never asks a second time.
- On Android 10 and older the app now actually requests storage permission instead of only checking for it, which previously made those devices fall back to the app-private folder forever.
- After granting "all files access", Settings offers to move the library to Download/Comic, instead of leaving it in an app-private folder most file managers cannot show you.

### KongComic v1.5.5

**收藏**

- 全新的总览布局。打开收藏不再直接把你塞进某个文件夹的网格：每个文件夹自成一排横向书架，可以直接左右滑着看、显示里面有多少本，点「全部」才进去。在文件夹里按返回，会先回到总览。
- 底部新增「推荐」书架：按你收藏得最多的那个标签挑同类漫画，已经收藏的会自动剔除；拉不到数据就整块悄悄消失，不留一个空盒子。
- 侧栏的文件夹数量现在会在收藏/取消收藏后立刻跟上。

**漫画详情**

- 章节排序不再是「一个看起来永远一样的图标」，而是能看出当前是升序还是降序的双态开关；切换后停在原来的位置，不会被弹回顶部。

**列表**

- 翻页条从占满一整行的顶部区块，改成钉在屏幕底部的一条紧凑胶囊：单手拇指就够得到，也不用再滚到列表最底下才能翻下一页。
- 修复在分类页、发现页左右滑标签时会误触安卓系统返回手势。现在标签栏所在的区域已排除在系统返回手势之外，这两个页面也不再自己跟着横向拖动。

**存储与权限**

- 自动备份不再写死某个 Download 路径：依次尝试公共 KongComic 目录、应用外部存储、内部存储，并且把「我真的把这个文件写进去了」当作唯一判据。以前目录存在但写不进去时，每次备份都会失败，界面却只给一句笼统的报错。
- 修复「目录不可用」的红色提示消失得太早。换到别的文件夹后旧文件还留在原处，提示却没了；现在它会一直挂着，直到你真的回到原目录（或自己忽略掉）。
- 设置里新增「通知」一行：显示当前是否允许通知，点击直达系统通知设置页 —— 安卓 13+ 第一次拒绝后不会再弹第二次，之前一旦误拒就再也无法找回。
- 安卓 10 及以下现在会真正申请存储权限，而不是只在后台查一下。以前这些设备永远拿不到授权，只能待在应用私有目录里。
- 授予「所有文件访问权限」后，设置页会主动提供切换到 Download/Comic 的入口，而不是让你继续留在大多数文件管理器都看不到的私有目录。

- 授予「所有檔案存取權限」後，設定頁會主動提供切換到 Download/Comic 的入口，而不是讓你繼續留在大多數檔案管理員都看不到的私有目錄。

<!-- lang:ja -->
### KongComic v1.5.5

**お気に入り**

- レイアウトを刷新しました。お気に入りを開くと、いきなり特定フォルダのグリッドに入るのではなく、フォルダごとに横スクロールの棚が並びます。収録数も表示され、「すべて」を押して中に入ります。フォルダ内で戻る操作をすると、まず総覧に戻ります。
- 下部に「おすすめ」の棚を追加しました。最もよく使っているタグをもとに類似作品を選び、すでにお気に入りにあるものは除きます。取得できない場合は空の箱を残さず、そのまま棚ごと非表示になります。
- サイドバーのフォルダ件数が、お気に入り登録・解除の直後に反映されるようになりました。

**作品詳細**

- 章の並び順を、どちらが有効か一目で分かる二状態の切り替えに変更しました（以前は常に同じに見えるアイコンでした）。切り替えても章一覧の同じ位置にとどまります。

**一覧**

- ページ切り替えを、上部の幅いっぱいの行から画面下部に固定したコンパクトなバーに変更しました。片手の親指で届く範囲にあり、次のページのために一覧の末尾までスクロールする必要がなくなりました。
- カテゴリページと探索ページで、タブを横になぞると Android のシステム戻るジェスチャーに奪われる問題を修正しました。タブ部分をシステムの戻る領域から除外し、ページ自体の横ドラッグもやめました。

**ストレージと権限**

- 自動バックアップが Download 内のパスを決め打ちするのをやめました。公共の KongComic フォルダー、アプリ外部ストレージ、内部ストレージの順に試し、「実際にファイルを書き込めたか」を唯一の判定にします。以前はフォルダーが存在しても書き込めない場合、毎回失敗するのに一般的なエラーしか出ませんでした。
- 「フォルダーを利用できません」の警告が早く消えすぎる問題を修正しました。別のフォルダーに切り替えても元のファイルは残っているのに警告が消えていました。元のフォルダーに戻る（または自分で無視する）まで表示を続けるようにしました。
- 設定に「通知」の項目を追加しました。通知が許可されているかを表示し、システムの通知設定画面を開けます。Android 13 以降は一度拒否すると再確認されないため、以前は拒否したら復旧できませんでした。
- Android 10 以下で、ストレージ権限を確認するだけでなく実際にリクエストするようにしました。以前はこれらの端末では権限が得られず、常にアプリ専用フォルダーのままでした。
- 「すべてのファイルへのアクセス」を許可したあと、設定画面から書庫を Download/Comic に移せるようになりました。多くのファイルマネージャーから見えないアプリ専用フォルダーに置き去りにしないためです。
