## English

### KongComic v1.5.18

- **Fixed: "storage path unavailable" kept coming back.** A folder picked through the system picker is stored as `android://primary:Download/Comic`; every existence and write check handed that string straight to `dart:io`, which does not understand the prefix. A perfectly good folder therefore looked deleted on every launch, and both escape hatches — "use the original folder" and "restore on restart" — were blocked the same way. The SAF identifier is now translated to a plain path before anything touches the disk.
- **The source picker on the search page is one calm block.** Sources sit inside a light card with a hairline border instead of floating loose on the page, the first pill is "Select all", and tapping another source while only one is selected switches to it rather than quietly building a set. Searching a single source is the common case; it no longer takes two taps.
- **Search results: the two views are a segmented control, placed after the search bar.** "By source" and "Aggregate & dedupe" used to be two unrelated capsules that read like filters; they are now one 38dp segmented control, which is what a mutually exclusive choice should look like. The mode switch that used to sit on the search page is gone — which view you get follows from how many sources you picked.
- **Switching between those two views no longer re-runs the search.** Each view used to own its own request and was destroyed on every switch, so changing tabs showed skeletons again and hit every source twice. Requests now belong to the page: one round, both views read the same data.
- **One failing source no longer blanks the whole page.** A source blocked by Cloudflare used to take the aggregate grid down with it. Failures are now recorded per source: sources that answered keep their results, the failing one explains itself in the by-source view, and only a total failure shows an error page.
- **Favorites: selection is now visible in both themes.** Selection used to be a faint tint that all but disappeared on dark backgrounds, leaving the "N selected" title as the only clue. Selected cards now get a 2dp brand-red outline and a check mark on the cover, and the unselected state reserves the same width so nothing shifts when you tap.
- **A folder shows its own name as the title.** Opening "Reading" used to keep the header reading "Favorites", with nothing but the pill row to say where you were.
- **The "source · date" strip no longer eats the date.** On narrow cards the whole string was truncated from the right, so the one piece of information worth reading became "2026-1…". It now drops segments from the front and keeps the date intact.
- **"Add to favorites" appeared twice in the long-press menu.** The history and local-comic pages each supplied that entry, and the comic tile always added its own copy. The built-in one now steps aside when the page already provides it.
- **The favorites overview finally shows network favorites.** Favorites that live under a logged-in source were reachable only through the folder picker; the overview itself listed local folders and nothing else, leaving an "All favorites" card above a blank page. There is now a network section with one row per signed-in source. Covers are deliberately not fetched there — that would be one round trip per source just to paint the first screen.
- **Empty folders are listed instead of hidden.** A folder you had just created was invisible on the overview until something was in it, which reads as "the creation failed". They now sit in a single row of pills after the shelves; tap one to open it.
- **The "All favorites" card explains its number.** It counts local favorites only, so it could disagree with a shelf full of network items. A subtitle now says "Local · N folders".
- **Fixed: the pager under an error screen was a dead control.** With nothing loaded, the "page 1 / ?" bar and its arrows only produced the same error again.

- **长按菜单里「添加到收藏」出现两次。** 历史页和本地漫画页各自都提供了这一项，缩略图组件又固定插一条。页面自带同名项时，内置项现在会让位。

- **修复：错误页下面的分页栏是死控件。** 什么都没加载出来时，「页面 1 / ?」和两颗箭头点了只会再失败一次。

### KongComic v1.5.18

- **修正：「保存先パスが使用できません」が繰り返し表示される問題。** システムのピッカーで選んだフォルダーは `android://primary:Download/Comic` という形式で保存されますが、存在確認と書き込み確認はその文字列をそのまま `dart:io` に渡していました。`dart:io` はこのプレフィックスを理解しないため、正常なフォルダーが起動のたびに「削除済み」と判定され、「元のフォルダーを使う」「再起動後に復元」という二つの逃げ道も同じ理由で塞がっていました。ディスクに触れる前に SAF の識別子を通常のパスへ変換するようにしました。
- **検索ページのソース選択を 1 つのまとまりに。** ソースのピルはページ上に散らばらず、ヘアライン罫線の明るいカードの中に収まりました。先頭は「すべて選択」。1 つだけ選んだ状態で別のソースをタップすると、こっそり複数選択になるのではなく、そのソースに切り替わります。単一ソースの検索が最も多い使い方で、2 回タップさせる理由はありません。
- **検索結果の 2 つの表示を検索バー下のセグメントコントロールに。** 「ソース別に表示」と「統合して重複排除」は、以前は無関係な 2 つのカプセルでフィルターのように見えていました。排他的な二択はセグメントコントロールで表現すべきものです。検索ページにあったモード切り替えは削除しました。どちらの表示になるかは、選んだソースの数だけで決まります。
- **この 2 つの表示を切り替えても検索し直さなくなりました。** 以前はそれぞれが独自にリクエストを持ち、切り替えるたびに作り直されていたため、またスケルトンが表示され、すべてのソースへ二度アクセスしていました。リクエストはページ側に移し、1 回だけ実行して両方の表示が同じデータを読みます。
- **1 つのソースが失敗してもページ全体が白くなりません。** Cloudflare に阻まれたソースが、統合グリッドごと巻き込んでいました。現在はソースごとにエラーを記録します。応答したソースは結果を表示し、失敗したソースは「ソース別」で理由を出し、すべて失敗したときだけエラー画面になります。
- **お気に入り：選択状態がどちらのテーマでも見えます。** 以前は淡い色付けだけで、ダークではほぼ判別できず、タイトルの「N 件選択」だけが手がかりでした。選択したカードには 2dp のブランドレッドの枠と表紙のチェックが付き、未選択側も同じ幅を確保するのでタップしても位置がずれません。
- **フォルダーを開くと、そのフォルダー名がタイトルになります。** 「Reading」を開いても見出しは「お気に入り」のままで、下のピル列だけが現在地の手がかりでした。
- **「ソース · 日付」の帯が日付を削らなくなりました。** 幅の狭いカードでは右から省略していたため、最も読むべき情報が「2026-1…」になっていました。先頭の要素から落とし、日付は残します。
- **長押しメニューの「お気に入りに追加」が 2 つ出ていました。** 履歴ページとローカル漫画ページがそれぞれ項目を用意し、タイル側も常に 1 つ足していました。ページが同名の項目を出す場合は、内蔵の項目が譲るようにしました。
- **お気に入りの概要にネットワークお気に入りが表示されるようになりました。** ログイン中のソースに属するお気に入りはフォルダーピッカーからしか辿れず、概要はローカルフォルダーだけを並べていたため、「すべてのお気に入り」カードの下は空白でした。サインイン済みのソースごとに 1 行の「ネットワークお気に入り」セクションを追加しました。ここでは表紙を意図的に取得しません。最初の画面を描くためだけにソースごとに往復が発生してしまいます。
- **空のフォルダーは隠さず一覧に出すように。** 作成直後のフォルダーは中身が入るまで概要に出ず、「作成に失敗した」と読めていました。棚の後ろに 1 行のピルとして並び、タップで開けます。
- **「すべてのお気に入り」カードが数字の意味を説明します。** ローカルのお気に入りだけを数えるため、ネットワーク項目で埋まった棚と食い違うことがありました。副題に「ローカル · N フォルダー」を表示します。
- **修正：エラー画面下のページ送りバーが機能しない操作でした。** 何も読み込めていない状態で「1 / ? ページ」と矢印を押しても、同じエラーがもう一度出るだけでした。
