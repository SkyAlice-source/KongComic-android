## English

### KongComic v1.5.8

**Explore**

- The Recommended tab now uses the same grid as every other source: same tile size, same aspect ratio, same spacing. It used to carry its own padding and ratio, so covers came out slightly smaller and the rows looked looser.
- Removed the *Recommended* heading and the *Because you like …* line above the grid. The tab already tells you which list you are on; those two lines only ate the first screen.
- The back-to-top button is back on this tab. It had been dropped by an explicit empty placeholder.
- Pull down to shuffle to a new batch, from any scroll position and even when only a few results came back. The bottom button stays as a fallback and is renamed **Shuffle**, because it fetches the next page instead of reloading the same one.

**Favorites**

- Titles are back under each cover in the shelf view. They had been squeezed into the cover's bottom edge, where the *Chapter N · progress* pill also sits, and the slot height was hard-coded from the cover alone.
- Added a shared title-slot helper so the shelf, grid and list views reserve the same vertical space for a title.

**Localization**

- Translation lookup now falls back by language code. When the system reports a locale the table has no exact key for (for example `ja` instead of `ja_JP`, or `zh_Hans` instead of `zh_CN`), the whole table used to silently fall back to English. It now looks for a table of the same language first and only then falls back to English.
- Japanese fixes: the explore recommendation setting used the Chinese word 推薦 where Japanese wants おすすめ, and the shuffle label is now 別のおすすめ.

### KongComic v1.5.8

**探索**

- 推荐页改用与其它源完全相同的网格：格子尺寸、宽高比、间距一致。此前它自有一套内边距与比例，封面偏小、行距偏松。

### KongComic v1.5.8

**探索**

- 推薦頁改用與其他來源完全相同的網格：格子尺寸、長寬比、間距一致。先前它自有一套內距與比例，封面偏小、列距偏鬆。

- 書架檢視的書名回到封面下方。先前書名被塞進封面底邊，與「第X話·進度」膠囊爭位置，且槽高只依封面寫死。

### KongComic v1.5.8

**探索**

- おすすめページのグリッドを他のソースと完全に揃えました。タイルのサイズ、縦横比、間隔が同じになります。以前は独自のパディングと比率を持っていたため、表紙が少し小さく、行の間隔もゆるく見えていました。

- 本棚ビューの書名が表紙の下に戻りました。以前は表紙の下端に押し込まれ、「第X話・進捗」のピルと場所を争い、さらにスロットの高さが表紙だけから決め打ちされていました。

- 日本語の修正：探索ページのおすすめ表示設定で中国語の漢字「推薦」を使っていた箇所を「おすすめ」に、入れ替えボタンの文言を「別のおすすめ」に変更しました。
