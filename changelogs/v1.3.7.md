## What's Changed

- **Fixed: sharing an image could send a file instead of an image.** Some formats (AVIF, HEIC and others) were not recognised, so the shared file ended up with no extension — for example `1670_P1.` — and receiving apps had no idea it was a picture. The type is now always resolved, unsupported formats are converted to PNG before sharing, and the MIME type is passed explicitly. Sharing several images at once also works now.
- **Fixed: dialogs had a washed-out grey bar at the top.** The frosted-glass layer stayed on even when the title bar was meant to be fully transparent, painting a grey block over your content. Transparent bars no longer blur. Full-screen dialogs on phones also use a solid background instead of glass, which was just a smudge over scrolling text.
- **Source repositories: added update buttons and drag-to-reorder.** Both the repository list and a repository's catalogue can be reordered by dragging the handle; the order is remembered. Each repository and each source now has its own *Update* button, and the sources page has **Update all** at the top (now a labelled button instead of a bare icon).
- **Fixed: updating a single source did nothing.** Sources installed before repositories existed have no repository recorded, and the app fell back to a URL inside the script — which often downloads a web page, not a script. It now looks the source up by key across every repository you have, and remembers which repository it came from once an update succeeds.
- **"No repository linked" is now "No source repository linked"**, which reads better and matches how the rest of the page talks about sources.
- **The "Has update" filter now checks for updates on its own** instead of waiting for you to press something, and tells you when it is still checking, when everything is up to date, and when nothing matches the filter.
- Chinese, Traditional Chinese and Japanese translations were updated for all the new text.

## 更新内容

- **修复：分享图片时发出去的是文件而不是图片。** 部分格式（AVIF、HEIC 等）识别不出来，导致分享出的文件没有扩展名 —— 例如 `1670_P1.` —— 接收方根本不知道这是张图。现在类型一定会解析出来，不支持的格式会先转成 PNG 再分享，并显式带上 MIME 类型；多张图一起分享也正常了。
- **修复：对话框顶部有一条发灰的白块。** 标题栏明明设为全透明，玻璃模糊层却还在生效，在内容上糊出一块灰色。现在透明时不再做模糊；手机上全屏的弹窗也改为不透明底色，之前那层玻璃只会把滚动的文字糊成一团。
- **源仓库：新增更新按钮与拖动排序。** 仓库列表和仓库内的目录都可以拖动手柄排序，顺序会被记住；每个仓库、每个源都有自己的「更新」按钮，漫画源页顶部还有「更新全部」（现在是带文字的按钮，不再是一个光秃秃的图标）。
- **修复：单个源点更新没反应。** 在仓库功能之前安装的源没有记录归属，会回退到脚本里写的网址 —— 而那个网址下载的往往是网页而不是脚本。现在会按 key 在你所有仓库里查找该源，并在更新成功后自动记住它属于哪个仓库。
- **「未关联仓库」改为「未关联源仓库」**，读起来更顺，也和页面里其它说法一致。
- **「有更新」筛选现在会自动检查更新**，不用你先点一下；并且会分别提示「正在检查」「全部已是最新」和「没有符合筛选的源」。
- 同步更新了全部新增文案的简体中文、繁体中文与日文翻译。
