## English

### KongComic v1.5.7

**Explore**

- Added a **Recommended** tab as the first tab on Explore. It picks comics based on what you have favorited and read, and the refresh button at the bottom right swaps in a new batch. Turn it off under Settings → Explore → "Show recommendations on explore".
- Horizontal swipe to switch tabs is back on Explore and Categories: start the swipe inside the top band (about the first fifth of the screen) and the page changes; start it from the edge below that band and the system back gesture takes over as before.

**Favorites**

- The shelf view leans again, and the books no longer spill outside the row: row height, top padding and gap now compensate for the lean geometry instead of clipping it.
- Removed the pale edge that appeared around every cover. The spine gradient was being tinted by the cover's own inner padding, so it looked like a white border rather than a book.
- The top bar now matches every other root page: 20pt bold title aligned to the 16dp content baseline, flat icon buttons on the right, solid background with no blur.
- Section headers are tappable across the whole row, with a chevron at the end, and the horizontal cover rows fade out at the right edge.

**History**

- Replaced the pill-shaped tool strip with the same top bar as the other root pages: title plus flat icon buttons for layout, filter, multi-select and more.
- Fixed the top bar looking like a separate layer: it was a translucent blur, so covers scrolling underneath were smeared into the bar and left a faint band along its bottom edge. It is now a solid surface.

**Settings**

- Added search to Settings. It covers every category at once and matches both the English source string and the localized title.

**Security & Build**

- Hardened the in-app WebView: remote debugging is only enabled in debug builds, navigation is restricted to http(s), and the unused deep links were removed.
- Added a CI gate workflow that fails the build on missing translations, stale font sizes, undocumented setting keys, stray design tokens and similar regressions.

### KongComic v1.5.7

**探索**

- 探索頁新增「推薦」作為第一個分頁：依你的收藏與閱讀紀錄挑選漫畫，右下角按鈕可換一批。設定 → 探索 → 「在探索頁顯示推薦」可關閉。
- 恢復手指橫向滑動切換分頁：在頂部帶狀區（約螢幕上方五分之一）內起手橫滑會切頁，帶狀區下方的邊緣起手仍交給系統返回手勢。

**收藏**

- 書架檢視恢復斜放，且書不再超出該列：列高、上內距與間距改為依傾斜幾何補償，而非把傾斜裁掉。
- 移除每本書封面周圍那圈泛白的邊。書脊漸層被封面自身的內距染色，看起來像白邊而不是書脊。
- 頂欄與其他根頁面完全一致：20pt 粗體標題對齊 16dp 內容基準線、右上角平鋪圖示按鈕、純色不透明背景。

**歷史**

- 將膠囊狀工具列替換為與其他根頁面相同的頂欄：標題 + 平鋪圖示（版面 / 篩選 / 多選 / 更多）。
- 修正頂欄看起來「與內容分成兩層」：原本是半透明毛玻璃，下方滑過的封面被糊進欄體，欄底留下一條淡淡的色帶。現改為純色。

**設定**

- 設定頁新增搜尋：跨全部分類檢索設定項目，英文來源字串與在地化標題都能命中。

**安全與建置**

- 收緊內建 WebView：僅偵錯版允許遠端偵錯、導覽只放行 http(s)、移除無用深層連結。
- 新增 CI 門檻工作流：翻譯缺口、字級舊表、未登錄的設定鍵、游離的設計權杖等問題會直接讓建置失敗。

### KongComic v1.5.7

**探索**

- 探索ページの最初のタブに「おすすめ」を追加しました。お気に入りと閲覧履歴をもとに作品を選び、右下のボタンで別の一批に入れ替えられます。設定 → 探索 → 「探索ページに推薦を表示」でオフにできます。
- タブを指で横にスワイプして切り替える操作が復活しました。画面上部の帯（およそ上から 5 分の 1）の中でスワイプを始めるとページが切り替わり、その帯より下の端から始めた場合は従来どおりシステムの戻るジェスチャーになります。

**お気に入り**

- 本棚ビューが再び傾き、本が行からはみ出さなくなりました。行の高さ・上パディング・間隔を傾きの幾何に合わせて補正しています（傾きを切り取るのではなく）。
- 各表紙の周りに出ていた白っぽい縁を削除しました。背表紙のグラデーションが表紙自身の内側パディングで色を帯び、白い枠に見えていました。
- トップバーを他のルートページと完全に揃えました。20pt の太字タイトルが 16dp の内容基準線に揃い、右側はフラットなアイコンボタン、背景は無地でぼかしなしです。

**履歴**

- カプセル型のツールバーを、他のルートページと同じトップバーに置き換えました。タイトルとフラットなアイコン（レイアウト / フィルター / 複数選択 / その他）です。
- トップバーが「内容と二層に分かれて見える」問題を修正しました。半透明のぼかしだったため、下を流れる表紙がバーに滲み、下端に淡い帯が残っていました。無地に変更しています。

**設定**

- 設定ページに検索を追加しました。すべてのカテゴリを横断して設定項目を検索でき、英語の原文と翻訳後のタイトルのどちらでもヒットします。

**セキュリティとビルド**

- アプリ内 WebView を強化しました。リモートデバッグはデバッグ版のみ、遷移は http(s) に限定、未使用のディープリンクを削除しています。
- CI ゲートのワークフローを追加しました。翻訳の欠落、古いフォントサイズ表、未登録の設定キー、規約外のデザイントークンなどがあるとビルドが失敗します。
