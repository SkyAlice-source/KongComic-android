## English

### KongComic v1.5.11

- Fixes: input-dialog crash on slow confirm; "Save cover" going unresponsive when image loading failed; storage path silently lost; auto-backup cleanup runaway.
- Performance: scrolling no longer hits the disk per frame for thumbnails/custom covers; source-editor write-back and export cleanup moved off the UI thread.
- 22 async callbacks now guard against the page being left mid-request.
- All icon-only buttons carry tooltips; design tokens consolidated.
