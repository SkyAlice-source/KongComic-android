## English

### KongComic v1.5.4

**Storage**

- Fixed the storage folder you picked going "unavailable" after closing the app. The folder you choose is now remembered as your real choice; a failed probe only switches to a temporary folder for that one launch, and the next start retries your folder and quietly recovers. If the folder comes back (permission restored, SD card remounted), your library reappears without any manual step.
- Fixed the app silently recreating a library folder you had deleted, which produced a passing check with an empty library. Existability is now checked before writability.
- Fixed a bug that could wipe the whole library: with a plain path as your storage folder, picking that same folder through the system picker was treated as "migrate elsewhere", copying each file onto itself and then emptying the source directory. Both spellings of the same folder are now recognized as one.
- The "Ignore" button on the storage warning now actually sticks. Previously it cleared the banner but left the dead path saved, so the warning came back on the next launch.
- The warning also disappears once a migration succeeds.

**Favorites**

- Fixed a folder showing a non-zero count in the sidebar while the page was empty. The read-status filter is remembered between sessions, and the sidebar count ignores it, so a folder where every comic was already read looked "empty". When a filter hides everything, the page now says so and offers a "Clear filter" button instead of claiming the folder has no comics.

**Errors**

- Requesting network favorites while signed out now says you need to sign in, instead of "Unknown error".

### KongComic v1.5.4

**存储**

- 修复设置的存储文件夹在关闭应用后变成「不可用」。现在你选的目录会被当成真正的选择记住：探测失败只在本次运行内切换到临时目录，下次启动会重新尝试你的目录并静默恢复。目录重新可用时（权限补回来、存储卡重新挂载），书库无需任何手动操作就回来了。
- 修复应用会把已经删掉的漫画库目录悄悄重建的问题 —— 那会让校验「通过」，而书库其实是空的。现在先判断目录是否还在，再判断能不能写。
- 修复一个可能清空整座书库的 bug：当存储路径是普通路径、你又用系统选择器选了同一个文件夹时，会被当成「迁移到别处」，逐个文件「复制到自己身上」然后把源目录清空。现在同一个文件夹的两种写法会被识别为同一个。
- 存储警告上的「忽略」按钮现在真的生效了。之前它只关掉提示，却把失效路径留在原处，下次启动照样弹。
- 迁移成功后警告也会自动消失。

**收藏**

- 修复侧栏显示有数量、页面却是空的。阅读状态筛选会被记住，而侧栏数量不受筛选影响，所以「全部已读」的文件夹看起来像空的。现在筛选把所有漫画都藏起来时，页面会说明原因，并给一颗「清除筛选」按钮，而不是骗你说这个文件夹里没有漫画。

**错误提示**

- 未登录时打开网络收藏，现在提示「需登录」，不再显示「未知错误」。

### KongComic v1.5.4

**儲存**

- 修復設定的儲存資料夾在關閉應用程式後變成「無法使用」。現在你選的目錄會被當成真正的選擇記住：偵測失敗只在本次執行內切換到暫存目錄，下次啟動會重新嘗試你的目錄並靜默恢復。目錄重新可用時（權限補回來、記憶卡重新掛載），書庫無需任何手動操作就回來了。
- 修復應用程式會把已經刪掉的漫畫庫目錄悄悄重建的問題 —— 那會讓檢查「通過」，而書庫其實是空的。現在先判斷目錄是否還在，再判斷能不能寫入。
- 修復一個可能清空整座書庫的 bug：當儲存路徑是普通路徑、你又用系統選擇器選了同一個資料夾時，會被當成「遷移到別處」，逐個檔案「複製到自己身上」然後把來源目錄清空。現在同一個資料夾的兩種寫法會被識別為同一個。
- 儲存警告上的「忽略」按鈕現在真的生效了。先前它只關掉提示，卻把失效路徑留在原處，下次啟動照樣彈出。
- 遷移成功後警告也會自動消失。

**收藏**

- 修復側欄顯示有數量、頁面卻是空的。閱讀狀態篩選會被記住，而側欄數量不受篩選影響，所以「全部已讀」的資料夾看起來像空的。現在篩選把所有漫畫都藏起來時，頁面會說明原因，並給一顆「清除篩選」按鈕，而不是騙你說這個資料夾裡沒有漫畫。

**錯誤提示**

- 未登入時開啟網路收藏，現在提示「需登入」，不再顯示「未知錯誤」。

### KongComic v1.5.4

**ストレージ**

- 設定した保存フォルダがアプリを閉じたあとに「使用できません」になる問題を修正しました。選んだフォルダは本当の選択として記憶されます。検出に失敗しても一時フォルダに切り替わるのはその起動中だけで、次回起動時に元のフォルダを再試行して静かに復帰します。権限が戻ったり SD カードが再マウントされたりすれば、手動操作なしで書庫が戻ります。
- 削除した書庫フォルダをアプリがこっそり再作成してしまい、チェックは通るのに中身が空になる問題を修正しました。存在確認を書き込み確認より先に行うようにしました。
- 書庫全体が消えうる不具合を修正しました。保存パスが通常パスのときにシステムの選択画面で同じフォルダを選ぶと「別の場所への移行」とみなされ、各ファイルを自分自身にコピーしたうえで元のフォルダを空にしていました。同じフォルダの二通りの表記を同一として扱うようにしました。
- ストレージ警告の「無視」ボタンが実際に機能するようになりました。以前は表示を消すだけで無効なパスが残り、次回起動時にまた表示されていました。
- 移行に成功したときも警告が自動的に消えます。

**お気に入り**

- サイドバーに件数が出ているのにページが空になる問題を修正しました。閲覧状態フィルターは記憶される一方、サイドバーの件数はフィルターの影響を受けないため、すべて既読のフォルダが空に見えていました。フィルターですべて隠れたときは理由を表示し、「フィルターを解除」ボタンを出すようにしました。フォルダに漫画がないと誤解させる表示はなくなりました。

**エラー表示**

- 未ログインでネットワークお気に入りを開いたとき、「不明なエラー」ではなくログインが必要であることを表示するようにしました。
