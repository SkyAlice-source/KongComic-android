## What's Changed

> **Already on v1.3.10? Please update manually.** That build could show a grey screen on launch and never get past it — the in-app updater inside it cannot help you out. Install v1.3.11 from the release page below.

- **Fixed: the app could fail to start and show a blank grey screen.** Three new strings were added to the translation table with a wrongly shaped value (a nested object instead of plain text). Loading the table then threw, which left *every* translation unavailable, and the very first frame — while the app itself was still being set up — crashed on that. Because it happened before the app's own error screen could be installed, all you got was a plain grey window with no text and no way to recover. The affected entries are corrected, and this release is the first one you can actually start.
- **The translation table is now fault-tolerant.** One malformed entry can no longer wipe out every translation or take the whole app down with it: bad entries are skipped, the rest still applies, and if the table cannot be read at all the app falls back to the built-in (English) wording and keeps running.
- **Updating several comic sources at once is dramatically faster and more reliable.** Every single update used to rebuild the whole source list, which re-reads and re-runs every script on disk — so updating thirteen sources meant re-parsing the entire collection thirteen times. One script going wrong anywhere in that pile could take the rest of the batch with it. The list is now rebuilt once, after the last update finishes.
- **Fixed: updating a source from a repository page could install the wrong (older) script.** Tapping "Update" on a row used to resolve the download through the source's own recorded link, which can point at a *different* repository. The row kept showing the version of the repository you were browsing while the download quietly installed the same old file again, so the update never went away no matter how many times you tapped it. The entry you tapped is now the file that gets downloaded, and the source is re-linked to that repository.
- **A repository that lists a version its script file does not actually ship is now marked "Repository out of sync"** instead of looking like an update you can complete — the row no longer invites repeated taps that cannot change anything.
- **Each row in a repository page can now be reinstalled or uninstalled on its own.** When a row is already up to date (or marked "Repository out of sync") its button reads "Reinstall" and asks for confirmation before re-downloading the script, so a locally edited file is never wiped by accident. A trash icon next to it removes just that one source without touching the others.
- **Fixed: the second row of tags was cut off** on cards whose title wraps to two lines. The tag area reserved 4px less per row than the layout actually used, so the bottom of the last row was clipped.
- **Fixed: sources could stay listed under "has update" after they were already up to date.** Each check used to merge its result into the previous list instead of replacing it, so once a source had been reported it never left, and the "has update" filter would pin it there for the rest of the session.
- **Sources with an unusual version number no longer break the source list.** Version numbers like `1.2` or `1.0.0rc1` used to crash the comparison outright, which could take down the whole page or make an update check fail silently with no reason shown. They are now handled as ordinary versions.
- **Failure messages are no longer overwritten.** When a rebuild of the source list ran into trouble right after a failed update, its own error replaced the real reason, so you saw the wrong message.
- **Fixed crashes and stuck states found during a full-app review:**
  - Loading dialogs could fail to close (and hang the UI) because the null-check in the close logic was reversed.
  - A comic list whose page load failed would retry forever, spamming the same failed request.
  - The categories page crashed when a category was hidden by settings (tab controller length no longer matched its views).
  - The "add to network favorites" panel crashed on a load error (null folder list used without a guard).
  - Posting or retrying a chapter comment could leave the spinner spinning forever.
  - Picking a custom time range in image favorites crashed (the range object was never initialized).
  - Deleting the folder you were currently viewing in local favorites crashed with "no such table".
  - The ranking page crashed for a source that enabled the ranking page but shipped no ranking function.
  - Opening a local comic whose files were deleted externally crashed.
  - The webview bridge now ignores non-JSON messages instead of throwing.
- **Fixed wrong behavior:** the Explore tab ignored "tap to scroll to top" and the reader could lose/save the wrong reading progress when switching chapters or on dispose.
- **Fixed UI overflow:** three dialogs in Settings → About drew their content outside the dialog box; the "custom mirror template" row was missing; several auth prompts were hardcoded in Chinese and now follow the app language.

## 更新内容

> **已经装了 v1.3.10 的话请手动更新。** 那一版可能一打开就是灰屏、永远进不去，而且它自带的更新功能在这种情况下也救不了你——请到下面发布页下载 v1.3.11 覆盖安装。

- **修复：应用可能起不来，启动后只有一片灰色空白。** 新增的三条文案在翻译表里被写成了错误的形状（值是嵌套对象，而不是纯文本）。加载翻译表时直接报错，导致**所有**翻译都不可用；而整个应用还在初始化的**第一帧**就因此崩掉。由于这发生在应用自己的错误界面装上**之前**，你能看到的只有一片纯灰、没有文字、也无法自救。相关条目已修正，这一版是第一个能正常打开的版本。
- **翻译表现在有容错。** 单条格式错误的条目不会再连累整张表、更不会拖垮整个 App：坏条目会被跳过，其余翻译照常生效；万一整张表都读不出来，也会回退到内置英文文案继续运行。
- **大幅提升批量更新多个源的速度与稳定性。** 以前每更新一个源都会重建整份源列表——也就是把磁盘上的每个脚本都重新读取、重新执行一次。更新十三个源就等于把全部脚本反复解析十三遍，期间任何一个脚本出问题都可能拖垮整批。现在改为全部更新结束后只重建一次。
- **修复：在源仓库页点「更新」可能装回另一个仓库的旧脚本。** 以前点某一行的「更新」时，是按这个源自己记录的下载地址去解析的，而它可能指向*另一个*仓库。于是页面显示着当前仓库的版本，下载却悄悄装回了那个仓库的同一个旧文件，无论点多少次更新都不会消失。现在会下载你点的那一条对应的文件，并把该源的归属改到当前仓库。
- **仓库宣称的版本压根没提供时，条目会标注「仓库未同步」**，不再长得像一个能点完成的更新，避免反复点击却毫无变化。
- **仓库页的每条源现在支持单独「重装」和「卸载」。** 当某条已经是最新（或标注「仓库未同步」）时，按钮显示为「重装」并在重新下载前弹确认，避免误删本地手改的脚本；旁边的删除图标只移除这一个源，不影响其它源。
- **修复：标题折成两行时第二排标签被裁掉一部分。** 标签区域每行少留了 4px（按 4px 行间距估算，实际用的是 8px），导致最后一行的底部被裁切。
- **修复：已经不需要更新的源仍会留在「有更新」列表里。** 每次检查更新时是往旧列表里合并结果，而不是用本次结果替换，于是某个源一旦被报过就再也不会消失，「有更新」筛选会一直把它钉在里面。
- **版本号写法不常见的源不再导致列表异常。** 像 `1.2`、`1.0.0rc1` 这类版本号以前会直接让版本比较崩溃，可能整个页面打不开，或者让更新检查静默失败且不显示原因。现在会按普通版本号处理。
- **失败提示不再被覆盖。** 更新失败后重建列表如果自己出错，它抛出的错误会顶掉真正的失败原因，导致你看到的是另一条无关提示。
- **修复了全量审查中发现的崩溃与卡死：**
  - 加载弹窗可能关不掉（关闭逻辑的空判断写反了），导致 UI 卡住。
  - 某个分页加载失败后漫画列表会无限重试，反复发送同一个失败的请求。
  - 当某个分类被设置隐藏时，分类页会崩溃（Tab 控制器长度与视图数量不一致）。
  - 「加入网络收藏」面板在加载出错时崩溃（空收藏夹列表未做空判断）。
  - 发表或重发章节评论后，转圈可能永远停不下来。
  - 在图片收藏里选择自定义时间范围会崩溃（时间范围对象从未初始化）。
  - 在本地收藏里删除「当前正在查看的文件夹」会报「no such table」崩溃。
  - 排行榜页对「开启了排行榜入口却没提供排行函数」的源会崩溃。
  - 打开文件已被外部删除的本地漫画会崩溃。
  - WebView 桥接现在会忽略非 JSON 消息，而不是抛出异常。
- **修复错误行为：** 发现页会忽略「点按回到顶部」手势；阅读器在切换章节或销毁时可能丢失/存错阅读进度。
- **修复界面溢出：** 设置 → 关于 里三个对话框的内容画到了框外；「自定义镜像模板」那一行丢失；若干身份验证提示硬编码为中文，现在跟随 App 语言。

## 更新内容

> **v1.3.10 を入れている場合は手動で更新してください。** そのビルドは起動すると灰色の画面のまま先に進めず、内蔵の更新機能でも復旧できません。下のリリースページから v1.3.11 を上書きインストールしてください。

- **修正：起動できず、灰色の空白画面のままになることがありました。** 新しく追加した 3 つの文言が、翻訳テーブルに誤った形（プレーンテキストではなくネストしたオブジェクト）で書き込まれていました。テーブルの読み込みが例外を投げ、**すべての**翻訳が使えなくなったうえ、アプリ自身の初期化中である**最初のフレーム**がそこでクラッシュしました。これはアプリ独自のエラー画面が組み込まれる**前**に起きるため、表示されるのは文字もない灰色の画面だけで、復旧する手段もありませんでした。該当エントリを修正しました。このバージョンが、実際に起動できる最初のリリースです。
- **翻訳テーブルが壊れた 1 件に耐えるようになりました。** 形式の誤ったエントリが 1 つあるだけで翻訳全体が失われたり、アプリごと落ちたりすることはありません。壊れたエントリはスキップして残りはそのまま適用し、テーブル自体が読めない場合も組み込みの英語表記にフォールバックして動作を続けます。
- **複数ソースの一括更新が大幅に高速化・安定化しました。** これまで 1 件更新するたびにソース一覧全体を再構築していたため、ディスク上の全スクリプトを読み直して再実行していました。13 件の更新は全スクリプトを 13 回解析し直すのと同じで、その途中で 1 つでも問題があれば残りの処理にも影響していました。最後に 1 回だけ再構築するようにしました。
- **修正：リポジトリページからの更新で、別リポジトリの古いスクリプトが入ってしまう問題。** 以前は行の「更新」を押すと、そのソース自身が記録しているダウンロード先で解決していましたが、それが*別の*リポジトリを指していることがあります。画面には閲覧中のリポジトリのバージョンが出たまま、実際にはその古いファイルを入れ直すだけだったため、何度押しても更新は消えませんでした。タップした行のファイルをダウンロードし、ソースの紐付けもそのリポジトリへ付け替えます。
- **リポジトリが掲載しているバージョンのスクリプトを実際には配布していない場合、「リポジトリ未同期」と表示**するようにしました。何度押しても変わらない更新として見えなくなり、無駄な再試行を促しません。
- **修正：タイトルが 2 行になるカードで、2 行目のタグの下部が切れていました。** タグ領域が実際の行間（8px）ではなく 4px で計算されており、1 行あたり 4px 足りず最終行の下端が欠けていました。
- **修正：更新が不要になったソースが「更新あり」に残り続ける問題。** 更新チェックの結果を毎回置き換えるのではなく既存の一覧にマージしていたため、一度報告されたソースが消えず、「更新あり」フィルターに残り続けていました。
- **特殊なバージョン表記のソースが一覧を壊さなくなりました。** `1.2` や `1.0.0rc1` のようなバージョンは以前は比較処理がそのままクラッシュし、ページ全体が開けなくなったり、理由を表示せずに更新チェックが失敗したりすることがありました。通常のバージョンとして扱います。
- **失敗メッセージが上書きされなくなりました。** 更新失敗直後の再構築でエラーが出ると、本来の失敗理由が差し替えられ、関係のないメッセージが表示されることがありました。
- **全体レビューで見つかったクラッシュ・フリーズを修正：**
  - 読み込みダイアログが閉じず（クローズ処理の null 判定が反転していた）、UI が止まることがあった。
  - 1 ページの読み込みに失敗した漫画一覧が無限に再試行し、同じ失敗リクエストを繰り返していた。
  - 設定でカテゴリを非表示にしたときカテゴリページがクラッシュ（タブコントローラーの長さとビューの数が一致しない）。
  - 「ネットワークお気に入りに追加」パネルが読み込みエラー時にクラッシュ（空のフォルダ一覧の null 判定漏れ）。
  - 章コメントの投稿・再試行後、インジケーターが永遠に回り続けることがあった。
  - 画像お気に入りでカスタム期間を選ぶとクラッシュ（期間オブジェクトが未初期化）。
  - ローカルお気に入りで「現在表示中のフォルダ」を削除すると「no such table」でクラッシュ。
  - ランキングページが「ランキング入口を有効にしたのにランキング関数を提供していない」ソースでクラッシュ。
  - 外部で削除されたローカル漫画を開くとクラッシュ。
  - WebView ブリッジは JSON 以外のメッセージを無視するようになり、例外を投げなくなりました。
- **誤動作を修正：** 探索タブが「タップで先頭へスクロール」を無視していた；リーダーが章切り替え時や破棄時に読書進度を失ったり誤って保存したりすることがあった。
- **UI のはみ出しを修正：** 設定 → バージョン情報の 3 つのダイアログでコンテンツが枠の外にはみ出していた；「カスタムミラーテンプレート」の行が抜けていた；いくつかの認証プロンプトが中国語に固定されていたのをアプリの言語に追従するようにした。
