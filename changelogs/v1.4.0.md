## English

### KongComic v1.4.0

- **Unified button system**: replaced raw Material `FilledButton` / `TextButton` / `OutlinedButton` across the app with a self-drawn `Button` family (`filled` / `outlined` / `text`) — consistent 16dp radius, brand-appropriate disabled states, and no more oversized full-screen dialog buttons.
- **Dialog surface lock**: a global `DialogThemeData` now pins native dialog surfaces so every confirmation / delete sheet looks identical.
- **Follow-updates page**: "Mark all as read" now uses a tick icon; the per-folder "N updated" badge switched from error-red to a brand-accent pill; the info box became a filled card; all dialog buttons unified.
- **Local & Downloads pages**: import / list entries and download task rows are now the same capsule cards as the home page; each download task is its own separated card (hairline + 16dp radius) instead of one stacked list.
- **Reader settings de-layered**: the settings app bar now follows the page background for a single-surface look; the in-reader settings panel keeps a matching overlay color so the glass blur stays clean.
- **New `KcSwitch`**: a compact 44×26 capsule toggle replaces the bulky Material switch in settings rows.
- **Design-token cleanup**: semantic `kc*` tokens plus a 3-appearance color system (AMOLED grayscale / brand-dark / light) underpin the above.
