## English

### KongComic v1.5.14

- Empty states now use the chibi idle illustration, completing the loading (crawl) / empty (idle) / error (warning) visual trinity — a blank screen no longer looks like a failed load.
- Search page restyled to match the settings page visual language: shared section headers, the same list tiles, unified capsule chips.
- The search options dropdown was rebuilt on the shared capsule + menu components so it no longer looks "cut out" of the page.
- Favorites, history and tools pages were consolidated onto reusable components (chibi, cover, quick search) and refreshed — fewer one-off widgets, consistent spacing and touch targets.
- History page rewritten on the shared list shell: grouping, selection and deletion now behave the same as favorites.
- Cover loading hardened: cache and error paths no longer leave a permanently blank cover.
- Version bumped to 1.5.14+193.
