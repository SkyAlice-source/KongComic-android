## What's Changed

- Fixed some sources (e.g. Baozi Manhua) remaining blocked after Cloudflare verification: the WebView now falls back to `document.cookie` to capture `cf_clearance`
- Fixed "Check for updates" still reporting failure after one failed download: APK integrity now also checks the EOCD record, and stale files are cleared before re-downloading
- The update dialog now shows the changelog in the system language automatically (Chinese / English / Japanese)
- The comic source list now supports "Pin to top" so long lists no longer need repeated dragging to reorder
- Unlogged errors on the Explore page now show a friendly localized message with a button to jump to that source's login page and auto-retry after signing in
