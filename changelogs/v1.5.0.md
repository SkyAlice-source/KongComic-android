## English

### KongComic v1.5.0

- **Favorite corner-fold badge**: replaced the white-circle-with-heart favorite marker with a book corner-fold badge (3-tier gradient + crease shadow + highlight edge) that reads as a physical dog-eared page — more volume and on-brand.
- **Removed "Read Later"**: folded into the favorites system; old Read Later data is auto-migrated and no longer mis-shows as "favorited".
- **Accent-color finalization**: migrated the last remaining `cs.primary` usages to brand design tokens, unifying the brand red across light / dark / AMOLED appearances.
- **Comic-source auto-update (opt-in)**: a new settings toggle silently updates comic sources in the background (WiFi/Ethernet only, once per day throttled). Note: it overwrites locally edited source scripts.
- **Backup cleanup by retention**: auto-backup now prunes old backups by age (7 / 30 / 90 / 180 / 365 days, default 30) with a 10-copy count cap as a fallback.
- **Bug fixes**: fixed a crash in the favorites "network" group (PageStorage key collision); fixed the follow-updates "check complete" notification sticking around (auto-dismiss via `timeoutAfter`).

### KongComic v1.5.0

- **收藏角标改为书角折角**：用「书页折角」替代原来的白圆 + 红心标记（三档渐变 + 折痕投影 + 高光棱边），更有体积感、更贴合品牌。
- **移除「稍后阅读」**：并入收藏体系；旧「稍后阅读」数据自动兼容，不再误显示为「已收藏」。
- **强调色收口**：残余 `cs.primary` 用法全部迁移到品牌设计令牌，亮色 / 暗色 / AMOLED 三套外观统一品牌红。
- **漫画源自动更新（默认关）**：设置新增开关，后台静默更新漫画源（仅 WiFi / 有线、每日节流一次）；注意会覆盖本地手改的源脚本。
- **备份按保留期清理**：自动备份新增按天数清理（7 / 30 / 90 / 180 / 365 天，默认 30），并以保留 10 份数量上限兜底。
- **Bug 修复**：修复收藏「网络」分组崩溃（PageStorage key 冲突）；修复追更「检查完成」通知常驻不消失（`timeoutAfter` 自动撤销）。

### KongComic v1.5.0

- **收藏角標改為書角折角**：以「書頁折角」取代原本的白圓 + 紅心標記（三檔漸變 + 折痕投影 + 高光稜邊），更有體積感、更貼合品牌。
- **移除「稍後閱讀」**：併入收藏體系；舊「稍後閱讀」資料自動相容，不再誤顯示為「已收藏」。
- **強調色收口**：殘餘 `cs.primary` 用法全部遷移到品牌設計令牌，亮色 / 暗色 / AMOLED 三套外觀統一品牌紅。
- **漫畫源自動更新（預設關）**：設定新增開關，背景靜默更新漫畫源（僅 WiFi / 有線、每日節流一次）；注意會覆蓋本地手改的源腳本。
- **備份按保留期清理**：自動備份新增按天數清理（7 / 30 / 90 / 180 / 365 天，預設 30），並以保留 10 份數量上限兜底。
- **Bug 修復**：修復收藏「網路」分組崩潰（PageStorage key 衝突）；修復追更「檢查完成」通知常駐不消失（`timeoutAfter` 自動撤銷）。
