## English

### KongComic v1.5.22

- Home stacked cards: an even seam on all four sides of every card, softer shadows and a faded lower edge — no more cut-off corners or hard grey band.
- Covers now fill their frames; the image-favorites toolbar matches Favorites; floating pagination no longer leaves a blank strip below the list.
- All comic sources show up in Search again; toggling multi-select no longer resizes the whole grid.
- Reader: fixed image preloading (downloads now run to completion), tolerant preload count, cancel in-flight preloads on exit, and proper edge-to-edge system bars on Android 15.
- WebDAV sync: downloads now merge instead of replacing local data, keeping favorites, history, comic sources and logins added since the last upload; uploads always use the privacy-safe snapshot; fixed snapshot ordering and duplicate uploads.
