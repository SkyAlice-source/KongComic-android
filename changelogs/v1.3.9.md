## What's Changed

- **Updating sources now tells you what actually failed.** Previously "Update all" could end with nothing but a count — *13 sources could not be updated* — with no hint of which ones or why. Failures are now listed one by one, each with its source name and the reason it failed.
- **Real failure reasons instead of a generic message.** Network problems were flattened into a single "Failed to update source" line, hiding everything useful. You now see what actually happened, such as *Server returned 404* or *Network error (connectionTimeout)*.
- **Fixed: a source could stay marked as updatable no matter how many times you updated it.** Repository indexes are cached per file for hours at the CDN edge. Checking for updates now reads the current index instead of the cached one, so a source no longer keeps offering an update that is already installed.
- **Fixed: a version list inside a repository could show stale numbers after updating a single source.** The page was still comparing against the snapshot taken before you tapped update, so the installed and available version could disagree.
- Translations were updated.

## 更新内容

- **更新源失败时会告诉你具体原因。** 以前「更新全部」结束只剩一个数字——「13 个源更新失败」，既不知道是哪些源，也不知道为什么。现在会逐条列出失败的源名称和对应的失败原因。
- **不再把失败原因笼统抹平。** 网络类问题以前一律被压成一句「Failed to update source」，有用的信息全丢了。现在会显示真实情况，例如「Server returned 404」或「Network error (connectionTimeout)」。
- **修复：某些源反复更新却始终显示可更新。** 仓库索引在 CDN 上按文件缓存数小时。现在检查更新会读取最新索引而不是缓存的那一版，源不会再一直提示一个早已装好的更新。
- **修复：在仓库里单独更新某个源后，版本号可能显示不一致。** 页面此前仍在使用点击更新之前那份快照做对比，导致「已安装」与「可更新」两个数字对不上。
- 同步更新了翻译。

## 更新内容

- **ソース更新の失敗時に、実際の原因が分かるようになりました。** 以前は「すべて更新」を実行しても「13 件のソースを更新できませんでした」と件数だけが表示され、どれが・なぜ失敗したのか分かりませんでした。失敗したソース名と理由を 1 件ずつ一覧表示します。

- **修正：リポジトリ内で 1 件だけ更新した際にバージョン表示が食い違う問題。** 更新をタップする前に取得したスナップショットで比較していたため、「インストール済み」と「更新可能」のバージョンが一致しなくなることがありました。
