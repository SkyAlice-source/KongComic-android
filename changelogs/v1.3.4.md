## What's Changed

- **Fixed: the update finished downloading but never installed.** The APK moved to the app's private files directory in v1.3.2, but the FileProvider path config still only allowed the old cache directory, so handing the file to the system installer always failed. Also jumps to the system "install unknown apps" setting when that permission is missing, instead of failing silently.
- **Download notification progress bar is actually visible now.** It was posted at low importance, which Android folds into the silent-notification section; it now uses normal importance (no sound), shows an indeterminate bar while comic info is still being fetched instead of sitting at 0%, and the error notification can finally be swiped away.
- Added a "Download complete" notification (tapping it opens the local library) and a "Packaging…" status while CBZ archives are built, so a finished queue no longer looks like a dead download.
- A failed download no longer blocks the queue: it moves to the back so the next comic starts instead of the failed one being retried forever.
- Storage moves are now mutually exclusive with downloads and imports (previously a concurrent download could write into the directory being moved away, risking data loss), and in-flight tasks are remapped to the new path.
- Local and imported files sort naturally (`page_2` before `page_10`, instead of `page_10` first).
- New setting: webtoon side margin (0–30%) for the vertical continuous reader.
- Follow-update checks are rate-limited per source (max 2 concurrent) with a 45s timeout per comic, so a slow source can no longer stall the whole check.
