## English

### KongComic v1.5.15

- **Update downloads can be cancelled, and no longer pile up.** The background download had no stop control at all, and asking to check for updates again started a second pipeline writing to the same temp file — a slow link looked frozen and left several progress notifications behind. There is now a Cancel button in the notification shade and in the app, and a second request joins the running download instead of starting another.
- **Cloud sync (WebDAV) is now reachable from settings.** The sync engine already existed but had no entry point, so nobody could open it. Settings → App → Cloud Sync now lets you enter a WebDAV server (Nextcloud, Synology, a self-hosted box), test the connection, and push or pull your data. Uploads rotate by date and version, so an accidental overwrite never costs you the previous backup.
- **Reader no longer burns mobile data preloading the next chapter.** Prefetching the chapter after the current one now only happens on Wi-Fi or wired networks. On cellular it waits until you actually turn the page.
- **Downloads resume themselves.** Tasks interrupted by a reboot or by the phone going to sleep used to come back stuck on "paused" and needed a manual tap. The queue now restarts on its own, while still honouring tasks you paused yourself.
- **Pause state survives restarts.** Manually paused downloads stay paused until you resume them instead of silently restarting.
- **Fixed: timers inside comic sources never fired.** The JS bridge had a placeholder `setTimeout` that relied on a promise the engine does not always return, so source scripts that delay or poll simply never continued. Timers are now driven by real Dart timers across the bridge, and `setInterval` / `clearTimeout` / `clearInterval` all work.
- **Fixed: a favourite folder could show a count of 0.** The badge now falls back to the database when the in-memory count is missing, and no longer double-counts a newly added comic.

### KongComic v1.5.15

- **更新下载可以取消了，也不会再叠出好几份。** 后台下载原本没有任何停止入口，而再次点「检查更新」会另起一条流程去抢同一个临时文件——慢网络下就表现为「卡着不动 + 通知栏好几条进度」。现在通知栏和 App 内都有取消按钮，重复请求会并入正在跑的那一次，而不是重新开始。

- **阅读器不再偷跑流量预载下一章。** 预取下一话只在 Wi-Fi 或有限网络下进行；移动数据下会等你真的翻页再去拿。

- **閱讀器不再偷跑流量預載下一話。** 預取下一話只在 Wi-Fi 或有線網路下進行；行動網路下會等你真的翻頁再去拿。
- **下載會自己續上。** 重開機或手機休眠打斷的任務，以前恢復後一律卡在「已暫停」，必須手動點一下。現在佇列會自己重新跑起來，同時仍尊重你手動暫停的任務。

- **修復：收藏夾角標偶爾顯示 0。** 記憶體計數缺失時會回落到資料庫查詢，同時不再把剛加入的書重複多算一本。

<!-- lang:ja -->
### KongComic v1.5.15

- **更新のダウンロードを中止でき、重複もしなくなりました。** バックグラウンドのダウンロードには停止手段がなく、もう一度「更新を確認」を押すと同じ一時ファイルを奪い合う別の処理が走っていました。低速回線では「固まったまま + 通知が複数」に見えていた原因です。通知シェードとアプリ内に中止ボタンを追加し、重複リクエストは実行中のダウンロードに合流するようにしました。
- **クラウド同期（WebDAV）に設定から到達できるようになりました。** 同期エンジン自体は以前から存在していましたが入口がなく、実質使えない状態でした。「設定 → APP → クラウド同期」で WebDAV サーバー（Nextcloud、Synology、自前ホストなど）を入力し、接続テスト・アップロード・ダウンロードができます。アップロードは日付とバージョンで世代を保持するため、誤って上書きしても前のバックアップが残ります。
- **リーダーが次話の先読みでモバイル通信を消費しなくなりました。** 次の話の先読みは Wi-Fi または有線接続時のみ実行し、モバイル回線では実際にページをめくった時点で取得します。
- **ダウンロードが自動で再開します。** 再起動やスリープで中断されたタスクは、以前は「一時停止」のまま復帰し手動操作が必要でした。キューが自動で再開するようになり、ご自身で一時停止したタスクはそのまま維持されます。
- **一時停止の状態が再起動後も保持されます。** 手動で止めたダウンロードが勝手に再開されることはありません。
- **修正：漫画ソース内のタイマーが発火しない問題。** JS ブリッジの `setTimeout` はプレースホルダ実装で、エンジンが必ず返すとは限らない Promise に依存していたため、遅延やポーリングを使うソーススクリプトが停止していました。タイマーは Dart 側の実 Timer でブリッジ経由に駆動され、`setInterval` / `clearTimeout` / `clearInterval` も利用できます。
- **修正：お気に入りフォルダの件数が 0 と表示されることがある問題。** メモリ上のカウントが無い場合はデータベース参照にフォールバックし、追加直後の作品を二重に数えることもなくなりました。
