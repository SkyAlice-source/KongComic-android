### KongComic v1.5.17

- **Settings are now split into eleven pages that each fit on one screen.** Reading & images, Paging & interface, Appearance, Discover, Library, Network, Downloads & import, Data & backup, App & storage, Permissions and About. Reader and app settings stay a single screen shown in two sections instead of two copies that drift apart, and every entry in the search index was remapped to its new page.
- **Permissions got their own page, and the list is finally complete.** Storage access (all-files access, plus "use Download/Comic") and system permissions — notifications, unrestricted battery usage, installing unknown apps — each show live status and jump straight to the relevant system screen. A line at the top says all of them are optional and only affect the matching feature.
- **New: unrestricted battery usage.** Follow-up checks and automatic backups run through WorkManager, which Doze — and MIUI, EMUI and ColorOS more aggressively — can postpone indefinitely. The symptom is "the switch is on and I have never received a notification". A row now reports the current state and opens the system prompt; when it is already exempt it skips the dialog, which would otherwise look like a dead button.
- **Fixed: on Android 10 the storage permission looked granted while writing still failed.** The `requestLegacyExternalStorage` flag now makes the permission bit we read and the system's actual scoped-storage behaviour agree. Android 11+ ignores the flag, so nothing is relaxed on newer releases.
- **Fixed: every "open link" button did nothing on Android 11+.** The manifest had no package-visibility `queries` for http/https, so the platform reported no browser that could handle the intent — the About page, source registration, "open release page" and links inside comments all went silent. Declared the two official intents.
- **Appearance is direct instead of nested.** Four preview cards choose the theme mode, eight dots choose the accent colour, one tap each, no menu. Language moved to App settings under "Language & startup", and a footnote states that the accent colour only applies to light mode — dark stays brand red and AMOLED is pure greyscale, which used to read as "changing the colour does nothing".
- **Fixed: an old accent colour could blank the Appearance page.** A colour that has since been removed made the page throw while building; it now falls back to the system palette, matching what the app actually applies.
- **The storage picker refuses a volume root.** Picking the root used to silently make the whole internal storage the library folder, so comics and backups scattered into it and "move here" would sweep in unrelated files. Choosing a root now explains which kind of folder to pick; a real subfolder like `Download/KongComic` still works.
- **The comic source page keeps its three-row cards, wearing the settings-page material.** Name, status badges and the three actions stay where they were; the pills became small 8dp chips with a faint same-hue tint instead of solid brand-red capsules, and the URL box plus its three buttons are back inside a single card with the input style used across settings.
- **Loading states now speak one language.** Six full-block spinners became the chibi character crawling along the track (grid footer, repository catalogue, source checks, web viewer, page picker), the remaining in-button rings became one hand-drawn thin arc at three sizes, and image loading in the viewer shows a progress bar with a real percentage instead of a ring with no number. Where a page is a skeleton and a spinner would say the same thing twice, the spinner is gone and a slow-network hint fades in after seven seconds instead.
- **Fixed: "Null check operator used on a null value" when a source fails without a message.** Download tasks, login-expiry detection and the user-facing error text all assumed a non-empty `message` in the source's error object; they now fall back to "the source returned nothing — it may be unavailable or have changed". Error text also stopped swallowing the Cloudflare marker, so the "needs Cloudflare verification" button appears again instead of "unknown error".
- **Fixed: a directory picked through the iOS/macOS channel was copied into the cache first.** The handler never returned after reporting success, so it went on to copy the whole selected folder — potentially gigabytes — into the cache and reported success a second time.

- **設定を 1 画面に収まる 11 のページに分割しました。** 閲覧と画像／ページ送りと表示／外観／発見／ライブラリ／ネットワーク／ダウンロードと読み込み／データとバックアップ／アプリとストレージ／権限／このアプリについて。リーダー設定とアプリ設定は同じ画面をセクションで出し分ける形のままなので、二つの実装が食い違うことはありません。検索インデックスの 87 項目もすべて新しい分類に割り当て直しました。
