## What's Changed

- **Multiple comic source repositories.** Sources are no longer limited to a single list URL. Settings → Sources → *Repositories* lets you add, edit and remove any number of repositories, browse each one's catalog and install or update sources individually. Your previous list URL is migrated automatically on first launch, and every installed source now shows a badge with the repository it came from.
- **"Move to Download/Comic" now really uses the public Download folder.** It used to resolve to the app's private directory (which is also wiped when you uninstall), so the path looked like it never changed. When the "all files access" permission is missing, the app now explains it and opens the system settings page for you, then retries automatically.
- **Update failures finally tell the truth.** Downloading, verifying and installing are reported separately instead of everything being labelled "download failed", and an install failure offers *Install manually* plus a browser fallback rather than a pointless retry. If notification permission is denied, the update download now shows its progress inside the app. Old APKs from previous versions are cleaned up so the update folder stops growing.
- **Fixed: chapter links in the reader were a huge empty block.** The "next chapter" area is now a compact capsule showing the chapter name, with a matching "previous chapter" capsule at the start of a chapter; the text and padding scale with screen width, and the vertical gap is much smaller so you don't have to scroll a quarter of a screen to reach it.
- **Fixed: a download could silently freeze.** A write error (full disk, stopping a download) left an internal flag stuck, so remaining blocks waited forever — the progress bar just stopped with no error.
- **Fixed: a source that failed to update disappeared from the list** until the app was restarted.
- **Fixed: pausing a download and then starting another one silently resumed the paused task.**
- Updating all sources now fetches each repository catalog once instead of once per source, and reports repository-level and source-level failures separately.
- The download notification channel is only reset once, so your own notification settings for it are no longer wiped on every launch.

## 更新内容

- **支持多个漫画源仓库。** 漫画源不再受限于单一列表地址。设置 → 漫画源 →「Repositories」可添加、编辑、删除任意数量的仓库，浏览每个仓库的源目录并单独安装或更新。首次启动会自动迁移你原来的列表地址，已安装的源会显示来源仓库徽章。
- **「移动到 Download/Comic」现在真正指向公共下载目录。** 此前解析到的是应用私有目录（卸载时还会被一并删除），所以看起来路径"又变回去了"。缺少「所有文件访问」权限时会说明原因并跳转系统设置页，返回后自动重试。
- **更新失败不再一律显示"下载失败"。** 下载、校验、安装三个阶段分别提示；安装失败提供「手动安装」与浏览器下载两个出口，而不是无意义的重试。未授予通知权限时，更新下载会在应用内显示进度。旧版本的 APK 会被清理，更新目录不再越积越大。
- **修复：阅读器章节链接是一大块空白。** 上下章节区域改为紧凑胶囊并显示章节名，卷首新增对称的「上一话」胶囊；字号与内边距随屏幕宽度自适应，上下留白大幅收窄，不再需要多滑近四分之一屏才能点到。
- **修复：下载可能无声卡死。** 写盘出错（磁盘满、手动停止）会让内部标志卡住，其余分片无限等待 —— 进度条就此停住且不报错。
- **修复：更新失败的源会从列表消失**，重启应用才回来。
- **修复：暂停某个下载后再新建下载，被暂停的任务会被自动恢复。**
- 「更新全部」现在每个仓库的目录只拉取一次（原先每个源各拉一次），并按仓库级 / 单源级分别统计失败。
- 下载通知渠道只重置一次，不再每次冷启动都清掉你对该渠道的自定义设置。

## 更新内容

- **複数のコミックソースリポジトリに対応。** 単一のリスト URL に縛られなくなりました。設定 → ソース →「Repositories」からリポジトリを自由に追加・編集・削除でき、各リポジトリのカタログを参照して個別にインストール / 更新できます。既存のリスト URL は初回起動時に自動移行され、インストール済みのソースには出自リポジトリのバッジが表示されます。

- **更新失敗がすべて「ダウンロードに失敗」と表示されなくなりました。** ダウンロード / 検証 / インストールを個別に報告し、インストール失敗時は無意味な再試行ではなく「手動でインストール」とブラウザでのダウンロードを案内します。通知権限がない場合はアプリ内で進捗を表示します。旧バージョンの APK は削除され、更新フォルダが肥大化しません。
- **修正：読書画面の章リンクが大きな空白ブロックになっていた問題。** 前後の章は章名を表示するコンパクトなカプセルになり、章の先頭にも「前の話」カプセルを追加。文字サイズと余白は画面幅に応じて調整され、上下の余白も大幅に縮小したため、画面の 1/4 もスクロールせずに到達できます。
- **修正：ダウンロードが通知なく停止することがある問題。** 書き込みエラー（容量不足、停止操作）で内部フラグが残り、残りのブロックが永久に待機して進捗バーが止まっていました。
- **修正：更新に失敗したソースが一覧から消える問題**（再起動まで復帰しませんでした）。
- **修正：ダウンロードを一時停止してから別のダウンロードを開始すると、停止中のタスクが自動的に再開される問題。**
- 「すべて更新」時のカタログ取得をソースごとではなくリポジトリごとに 1 回に変更し、失敗もリポジトリ単位とソース単位で分けて報告します。
- ダウンロード通知チャネルのリセットは初回のみとなり、起動のたびにチャネル設定が消去されなくなりました。
