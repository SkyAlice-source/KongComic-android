## English

### KongComic v1.3.14

- **Local downloads page**: compacted the Sort / Delete / Delete-Chapters dialogs into centered cards (they no longer fill the whole screen on phones), and rewrote the import-menu labels so each option clearly describes what it actually imports.
- **Progress-bar hardening**: clamped the app-update download progress, the local export/import loading dialog, and the download-task bar to the valid `[0,1]` range, preventing assertion crashes when a mirror reports a wrong `Content-Length` or an oversized file size.
- **Crash fixes (16)**: crashes when resuming download tasks for an uninstalled source, a null external-storage path on some devices, a missing `orElse` in source settings, JS-engine access after a document was evicted, a null cookie domain, reader chapter-tab index overflow, double-tap / long-press zoom on an uninitialized controller, malformed `.download` state files, history source-key parsing, chapter-comment id, `setState` after dispose on the follow-updates page, out-of-range local-favorites access, and corrupted favorite-category data.
