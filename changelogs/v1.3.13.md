## What's Changed

- **Downloads now start automatically.** Adding a chapter to the download queue no longer leaves it stuck in a "paused" state — the queue resumes the head task as soon as it is added. A previous change had mis-flagged every fresh task as paused, so nothing ever started on its own.
- **Fixed a crash when typing in search.** The search suggestion list wrapped a sliver inside a repaint boundary, which broke the sliver layout protocol and crashed the moment you typed. The wrapper has been removed.
- **4399 source search works again.** Its search request was missing the form content type, so the server returned an empty page and the app reported a false "login required". The header is now set correctly.
