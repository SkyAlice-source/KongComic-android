## English

### KongComic v1.5.2

**Network reliability**

- Fixed requests that could hang forever on a dead connection: connect, send and receive are now each bounded by a 15s timeout. Failures surface as an error page in about 16 seconds instead of leaving you on a spinner (previously some requests never returned at all).
- Every loading state now falls back to an error page with a Retry button when a comic source throws an exception or the response cannot be parsed. No more skeleton screens stuck forever.
- New: a "Network is slow, still loading…" hint shows up after 7 seconds, so a slow connection is clearly different from a frozen app.
- Fixed a "Future already completed" crash that could be thrown while closing a connection.

**Error messages**

- Every error message is now shown in the app's language. Raw English strings — DNS failures, dropped connections, malformed comic source responses, HTTP 403/502 — no longer leak into the UI.

**Interface**

- List rows now have a 48dp minimum tap height, so they are no longer easy to miss (they were 43dp).
- Separators are no longer drawn after the last row of a list.
- Removed the doubled border around the proxy host / port / username / password fields.
- The error color in the light theme is deeper and less orange.
- The favorites page and the history page now draw their own top bar.

**Sharing**

- Shared images keep their original filenames instead of a random UUID.

**General**

- Filled in the missing Japanese translations.
