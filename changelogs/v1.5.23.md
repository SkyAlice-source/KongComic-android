## English

### KongComic v1.5.23

- A full stability sweep: 100+ fixes across the whole app, found by an audit of every page, the persistence layer and the network layer.
- Data safety: WebDAV sync now uploads the new snapshot before removing old ones (a network drop no longer wipes your backup); local backups are written atomically — no more half-written files after an interruption; fixed a deadlock that could silently lose reading progress; download cancellation no longer hangs.
- Favorites: deleting from the "All" view now removes the entry from the correct folder; batch move no longer corrupts data; folder rename no longer leaves ghost counts; creating a duplicate folder is handled cleanly.
- Sources: disabled or unloaded sources no longer crash the favorite panel, image loading or network favorites; fixed network favoriting passing the wrong folder id, which could remove the wrong entry; batch source updates count correctly.
- Downloads: canceling tasks completes properly; downloads queued before an app restart now actually resume; unknown task types are filtered out safely.
- Reader & UI: error pages now show the page title; settings switches and sliders persist reliably; comment actions no longer spin forever on failure; the exit confirmation checkbox works again; accidental back-gesture swipes during reading are reduced.
- Cleanup: removed duplicated internal components; a few rarely-used rough edges were simplified without removing any features.
