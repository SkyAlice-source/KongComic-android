## What's Changed

- **Comic source repositories now come pre-installed.** Two are added automatically on first launch — *KongComic Official* and *Community Sources* — served through jsDelivr so they load reliably from mainland China. Anything you delete stays deleted; a default introduced by a later version still shows up on its own.
- **The official repository grew from 33 to 63 sources**, adding 30 community-contributed scripts. It is now self-hosted instead of depending on an upstream repository we don't control.
- **Fixed: "拷贝漫画 (multi-account)" could not coexist with "拷贝漫画".** Both scripts declared the same internal key, so installing either one silently replaced the other. The multi-account variant now has its own key.
- **Repository page redesigned.** Repositories are cards that show how many sources they offer and how many of your installed ones have an update pending. Opening one gives you filters (All / Not installed / Installed / Updatable) plus batch install and batch update.
- **Glass surfaces are finally consistent.** The top bar now actually blurs what is behind it — the blur widget it relied on used to be an empty placeholder that did nothing. The plastic-looking mirror highlight and the hard glow outline are gone, so panels read as frosted glass instead of shiny plastic.
- **Tag colours are stable.** The same tag now always gets the same colour, on every page and across restarts. The old code used a hash with a random seed, so a tag could be blue today and pink tomorrow, and the same tag could disagree between pages.
- **Spacing follows Material 3**: 16 dp page margins, an 8 dp grid and uniform chips, replacing the scattered 6/7/10/12/20 dp values.
- **Smoother scrolling.** Background blur is skipped while a list is moving and restored 150 ms after it stops — you cannot tell the difference mid-scroll, but it removes the most expensive per-frame work. Blur strength was also lowered with no visible change.
- **Reader**: the bottom toolbar is shorter (125 → 100 dp) and translucent instead of an opaque slab, and the chapter picker uses the standard dialog.
- **Update downloads are verified.** Every APK's SHA-256 is published with the release and checked after download, so a corrupted or tampered file is reported as exactly that instead of failing later with a confusing install error.
- **Fixed: titles on the share page and chapter picker were nearly invisible on light backgrounds** — the global app-bar title style defined a size and weight but no colour, so the title fell back to almost-white text.
- **Fixed: leaving the sources page while an operation was running could crash** ("setState after dispose"), and *Test all* could stay stuck in its loading state forever if one source failed.
- **Fixed: the last item of a list could hide behind the floating bottom bar.** When the bar became a floating capsule it started covering 10 dp more than pages reserved for it.
- **Fixed: long-press save/copy could crash when a cached image file was damaged.** It now reports "No Image" like any other missing image.
- Chinese, Traditional Chinese and Japanese translations were completed for all the new screens.

## 更新内容

- **滑动更顺。** 列表滚动时暂时不做背景模糊，停止 150ms 后恢复 —— 滚动过程中肉眼分辨不出差别，却省掉了每帧最贵的一笔开销；模糊强度也下调了，观感不变。
- **阅读器**：底部工具栏更矮（125 → 100dp）且改为半透明，不再是一整块实心挡板；章节选择弹窗改用统一的对话框样式。
- **更新包增加完整性校验。** 每个 APK 的 SHA-256 会随发布一起公布，下载完成后本地校验；文件损坏或被篡改时会明确提示，而不是等到安装时才抛出莫名的错误。
- **修复：分享页与章节选择页的标题在浅色背景下几乎看不见。** 全局 AppBar 标题样式只定义了字号和字重、没有给颜色，导致标题回退成接近白色的文字。
- **修复：操作进行中退出漫画源页面会崩溃**（"setState after dispose"）；「测试全部」在其中一个源失败时会永久卡在加载状态。
- **修复：列表最后一项会被悬浮底栏挡住。** 底栏改成悬浮胶囊后，实际遮挡比页面预留的高度多出 10dp。
- **修复：长按保存/复制图片时，若缓存图片文件已损坏会崩溃。** 现在和其他取不到图的情况一样提示「No Image」。
- 补齐了所有新增界面的简体中文、繁体中文与日文翻译。
