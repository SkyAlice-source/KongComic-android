## What's Changed

- Update downloads now support resuming from breakpoints, and the failure dialog offers an "Open in browser" fallback (fixes repeated "download completes but keeps failing" on unstable networks)
- Cloudflare verification hardening: no longer auto-closes mid-challenge just because a stale clearance cookie exists; falls back to the Android native cookie API when `cf_clearance` is HttpOnly; case-insensitive UA matching; shows a hint when no verification cookie can be captured
- More auth / network / server errors are now localized (including "login expired"), and the Explore page shows a "Log in" button with auto-retry for unauthenticated sources
- The Android default download folder is now `Download/Comic`, with a one-tap "Move to Download/Comic" migration in Settings
- GitHub release notes use a collapsible layout (English on top) and no longer degrade to a placeholder
