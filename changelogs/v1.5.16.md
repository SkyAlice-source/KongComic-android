## English

### KongComic v1.5.16

- **One rounded-corner language for every input box.** Settings used to mix Material's square 4dp outlines (WebDAV sync, keyword blocking, source login, repository dialogs) with hand-rolled ones, and the dropdowns (backup interval, backup retention, category filters) were tiny right-angled boxes. All of them now share a single 16dp field radius driven by one token, so changing the roundness is a one-line edit.
- **Search sources are laid out in multiple rows.** Instead of one horizontally scrolling strip that cut the last chip in half, every enabled source is visible at once (capped at ~4 rows, scrolling inside that area if you really do have dozens).
- **The redundant "Search" label inside the search box is gone.** It appeared even when the box was empty, where it only repeated the placeholder and did nothing when tapped. It now shows up in brand colour only once there is something to submit.
- **The layout-toggle icon in the reader toolbar is no longer oversized.** It was painted edge-to-edge with a heavier stroke, so it read as a different icon set next to the magnifier and the overflow dots.
- **The storage-path warning now says what to do — and can move the files for you.** When the old storage folder disappears, the banner explains the two options and adds a **Move here** button that copies the old library into the current folder, after a confirmation that spells out which folder goes where and that the old one will be emptied. Previously the only way to keep the new path was to switch back and forth.
- **New: automatic webtoon detection.** The reader samples the first few pages, and when they are clearly tall strips it switches to continuous vertical scrolling. It only takes over from gallery mode, and there is a switch in Reader settings to turn it off.
- **Fixed: the storage migration could lose data silently.** Copying into a folder URI skipped files it failed to create, an empty recorded path resolved to the process working directory, and DocumentTree writes could report success with zero files transferred — all three were followed by "delete the old folder". Every copy is now verified file-by-file against the source before the old folder is touched.

<!-- lang:ja -->
### KongComic v1.5.16

- **アプリ全体の入力欄を一つの角丸に統一しました。** 設定には Material 標準の 4dp 直角枠（WebDAV 同期、キーワード遮断、ソースのログイン、リポジトリのダイアログ）と独自の角丸が混在し、ドロップダウン（バックアップ間隔・保持期間・カテゴリ絞り込み）は小さな直角の箱でした。すべて 16dp の入力欄用トークンに統一したので、丸みの調整は定数 1 か所で済みます。
- **検索ソースを複数行に並べました。** 横スクロール 1 行で最後のチップが半分切れる代わりに、有効なソースが一画面で見渡せます（上限は約 4 行、それ以上はその領域内でスクロールし、下の履歴を押し出しません）。
- **検索欄の中の余分な「検索」ラベルを削除しました。** 空のときにも表示され、プレースホルダーと重複するうえタップしても反応しませんでした。入力があるときだけブランド色で現れ、送信の入口になります。
- **リーダーのツールバーにあるレイアウト切替アイコンが大きすぎる問題を修正しました。** 18dp いっぱいに太い線で描かれていたため、隣の虫めがねや三点メニューと別系統のアイコンに見えていました。
- **保存先の警告が「どうすればいいか」を示し、ファイルの移動まで行えるようになりました。** 以前の保存フォルダーが使えなくなったとき、赤いカードが二つの選択肢を説明し、**ここに移動** ボタンを追加しました。どこからどこへ移すのか、移動後に元のフォルダーが空になることを確認ダイアログで明示したうえで、旧ライブラリを現在のフォルダーへコピーします。
- **新機能：ウェブトゥーンの自動判別。** 最初の数ページを抽出し、明らかに縦長の短冊であれば縦方向の連続スクロールへ切り替えます。ギャラリーモードからのみ切り替わり、リーダー設定でオフにもできます。
- **修正：保存先の移行でデータが黙って失われる可能性がありました。** フォルダー URI へのコピーで作成に失敗したファイルが飛ばされ、記録が空の旧パスがプロセスの作業ディレクトリとして解釈され、DocumentTree 経由の書き込みが「1 ファイルも入っていないのに成功」と報告することがあり、いずれもその直後に「旧フォルダーを削除」していました。現在はコピーのたびにファイル単位で照合してから旧フォルダーに触れます。
