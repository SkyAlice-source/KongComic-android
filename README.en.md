## Features

- **Multi-source search** — Aggregate search across multiple comic sources
- **Offline download** — CBZ packaging, read anytime
- **Local favorites** — Multi-level folders, custom covers
- **Reader** — Multiple page modes, auto-scroll, image caching
- **Backup & restore** — Favorites, settings, covers in one click

## Build

```bash
flutter pub get
flutter build apk --release --split-per-abi
```
